assured_workload Reglas de Integridad & DDL Estricto

Clave Foránea: pedidos.id_cliente

Garantiza que ningún pedido sea huérfano. La regla ON DELETE RESTRICT impide dar de baja un cliente mientras conserve pedidos en histórico.

Restricción de Unicidad: comprobantes.id_pedido

Un pedido solo puede emitir un único comprobante legal activo. Evita la doble tributación y desfase contable en caja.

Definición DDL (PostgreSQL)

-- Esquema de Red Pepper Fast Food
CREATE TABLE detalle_pedidos (
    id_detalle BIGSERIAL PRIMARY KEY,
    id_pedido INT NOT NULL REFERENCES pedidos(id_pedido) ON DELETE RESTRICT,
    id_producto INT NOT NULL REFERENCES productos(id_producto) ON DELETE RESTRICT,
    cantidad INT NOT NULL CHECK (cantidad > 0),
    precio_unitario NUMERIC(10, 2) NOT NULL,
    subtotal NUMERIC(10, 2) GENERATED ALWAYS AS (cantidad * precio_unitario) STORED
);
